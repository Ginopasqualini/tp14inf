# TP14 — Gestor de juegos responsivo

Catálogo web de videojuegos desarrollado como parte del Trabajo Práctico 14 (Recuperatorio), para **Laboratorio de Programación — 6.º G**. El proyecto presenta una tienda de juegos adaptable a distintos tamaños de pantalla, con temática arcade y un enlace destacado al juego **Asteroids**, desarrollado previamente en TP10.

## Características

- Interfaz en español con tema oscuro de Bootstrap.
- Diseño responsivo con el sistema de grillas de Bootstrap.
- Secciones de catálogo, juego destacado y tabla de juegos.
- Enlaces al juego Asteroids y a su repositorio.
- HTML5, CSS y Bootstrap 5.3.3 integrado mediante CDN.

## Cómo verlo

Abrí `index.html` en un navegador o visitá la página publicada en GitHub Pages cuando Pages esté habilitado en la configuración del repositorio.

- **Tienda:** https://ginopasqualini.github.io/tp14inf/
- **Juego destacado — Asteroids (TP10):** https://ginopasqualini.github.io/tp10/
- **Repositorio del juego:** https://github.com/Ginopasqualini/tp10

## Tecnologías

- HTML5
- Bootstrap 5.3.3 (CDN)
- CSS

## Entrega

Este repositorio contiene la parte de gestor/tienda web del TP14. El videojuego enlazado es un proyecto independiente alojado en el repositorio `Ginopasqualini/tp10`.
